1. 计算机怎样处理文字

这一部分指的是将人类文字变成计算机可以看懂的输入，然后输入到计算机中，经过处理之后再输出成文字的过程。读完这部分后，我们应该可以区分字符编码、Token 切分和 Token ID 这些概念，知道信息在机器处理过程中的基本状态是什么。

1.1 字符、编码与数字

我们在屏幕上看到一个文字，例如“猫”时，作为一个客观存在的、有着自主思维的人类来讲，我们将“猫”这个文字作为载体存储到我们的大脑中，但计算机的存储以及信息的表示都基于一串又一串的二进制编码形成的数字，它在面对“猫”这个字的时候，通过已有的文本字符编号，将“猫”这个字映射到编号上，然后通过编码方式将编号映射成字节序列。

在这里要分清楚三个层次：

层次 例子 作用
人看到的文本 猫 人类阅读的文字
字符编号 Unicode 中对应的码点 在字符层面标识字符
编码后的字节 UTF-8 字节序列 供计算机存储和传输

比如我们得到一个字符“猫”，然后得到它的 Unicode 编号 U+732B，最后通过 UTF-8 编码方式得到对应的字节序列 E7 8C AB。这样我们就得到了一个字符如何转换为计算机可存储、表示的形式。

但这还不是 Transformer 所说的 Token 切分。字符编码解决的是将字符映射成计算机可理解的字节序列，使之可以表示和保存。Tokenizer 解决的是模型将输入的文本切分成多个处理单元。可以理解为一个重在将文本转化为可存储表示的字节，一个将字符切分为不同的 Token。具体可读下文。

1.2 Token

Token 是模型词表中的一个基本单位。它可能是一个完整的单词，或者一段单词，亦可是一个汉字、多个汉字，标点、空格等等。甚至某些字节片段中，Token 不一定是一个“词”，这由分词器 Tokenizer 决定。通常不同模型的 Tokenizer 处理同一段文本也可以得到不同的切分结果。

例如，把“我喜欢浙江工业大学”交给不同的 Tokenizer，可能得到这样的切分结果：

切分方式 Token 序列
一种可能 ["我", "喜欢", "浙江工业", "大学"]
另一种可能 ["我", "喜欢", "浙江", "工业", "大学"]

切分没有对错之分，也可能更细或更粗；实际结果由具体模型的 Tokenizer 决定。

为什么不直接一个字、一个单词就是一个 Token 呢？因为按字符切分会让 Token 序列变得很长，按完整词切分则会遇到词表过大、罕见词或新词难以处理的问题，子词切分让词表规模、序列长度之间做折中，也让模型通过熟悉的片段组合处理罕见的、未见得词性。

Token 数量会影响模型可处理的上下文长度以及计算量，同样长度的一段文字，切分的 Token 越多，占用的上下文通常越多。Token 是模型处理和理解世界的基本单位。

1.3 Token ID

Tokenizer 切分 Token 后，会查一张表，我们称之为词表，词表中把每个 Token 映射成一个整数，称之为 Token ID。假设现在存在一个词表如下：

示意词表（内容仅作说明，无具体含义）

Token Token ID Token Token ID
我 0 喜欢 1
浙江 2 工业 3
大学 4 和 5
今天 6 明天 7
晴天 8 阴天 9
天气 10 下雨 11
机器 12 学习 13
很好 14 。 15

如果我们得到一个 Token 序列为 ["今天", "天气", "很好"]，对应的词表中的 Token ID 为[6, 10, 14]。

当然这些数字只是示意，真实的编号由具体模型自身的词表决定。Token ID 的作用就是告诉程序该查哪一个 Token，并不表示一个 Token 多重要，编号距离相近也不影响 Token 之间的关系，同时不具有数值特征，不能说 "15" 就比 "4" 大或者好，仅仅表示一个离散的编号。

这里还要区分 Token ID 与模型实际计算的表示，ID只是离散的编号；进入神经网络后，模型会通过 Embedding 表把每个 ID 嵌入成一个向量，这个向量才是后续矩阵运算以及各种运算的输入。本文将在神经网络基础部分再细讲 Embedding。

Token ID 依赖 Tokenizer 的词表，因此同一个字符串交给不同的 Tokenizer 时可能会得到不同的切分结果以及不同的词表，因此使用一个预训练模型时必须配套的使用与之匹配的 Tokenizer。

1.4 特殊 Token 与词表

词表是 Token 与 Token ID 之间的映射表。模型输入时将 Token 转化为 ID，紧接着嵌入成向量，输出时也通常会词表里面的候选 Token 计算分数或概率。词表大小因此影响输出层的规模，可以理解为模型的 Token 候选集。

除了普通文本段外，词表或者输入协议中还包含特殊Token，例如：

特殊 Token 英文含义 作用
BOS Beginning of Sequence 标记输入或生成序列的开始
EOS End of Sequence 标记序列结束
PAD Padding 补齐不同长度的序列，便于批量处理
UNK Unknown 表示无法识别或表示的 Token；有些 Tokenizer 会尽量避免使用

当然不同模型不一定全部使用这些特殊标记，也不一定只含有这几个标记，这由具体的 Transformer 而定。

PAD Token 和后面要讲的 Attention Mask 也要区分开来。前者指的是一个填充位置可能使用的 Token，因为在把 Token 序列化为等长的时候，较短的序列可能采用 PAD 填补空缺；Mask 则是告诉模型应该的遮罩，即哪些位置信息应该被屏蔽。Mask 具体由后文的注意力机制章节展开讲解。

有了 Token 序列，就可以定义语言模型最常见的训练任务：给定前面的 Token，预测接下来那个 Token。注意，目标是下一个 Token，不一定是下一个完整单词，因为一个词可能被切成多个 Token。

比如一句话被切成["我", "喜欢", "浙江", "工业", "大学"]，训练时过程如下：

已有上下文 要预测的下一个 Token
BOS 我
BOS, 我 喜欢
BOS, 我, 喜欢 浙江工业
BOS, 我, 喜欢, 浙江工业 大学
BOS, 我, 喜欢, 浙江工业, 大学 EOS

模型学习的就是，看到已有上下文之后，预测下一个 Token 中哪一个更可能出现。比如看到 "BOS, 我, 喜欢" 之后，开始对下一个可能的 Token 进行预测，每个候选 Token 用概率记号可以写成：

P(ti+1∣t1,…,ti)P(t_{i+1}\mid t_1,\ldots,t_i) P(ti+1​∣t1​,…,ti​)

这里，t1,…,tit_1,\ldots,t_it1​,…,ti​ 是已经出现的 Token，ti+1t_{i+1}ti+1​ 是要预测的下一个 Token。公式的读法、下标和条件概率会在后面的符号与数学基础部分拆开讲。

举例说明，我们已有的 Token 上下文为 "BOS, 我, 喜欢"，可能得到的候选集如下：

假设在上下文 BOS, 我, 喜欢 下，模型得到以下示意概率：

候选下一个 Token 条件概率
浙江工业 0.40
学习 0.20
你 0.15
运动 0.10
浙江大学 0.10
其他候选 0.05

当然这个表只是用于演示假设的概率表，仅用作说明。其中 浙江工业 出现的概率最高，所以它是最可能出现的下一个 Token，所以选择它。

这里补充一句，贪心解码中就是选概率最大的，但这不是唯一的方法。实际生成中可能按概率随机抽，也可能筛一部分再抽，具体由解码策略决定。所以并不一定就是说就选概率最大的，不过这里以它为例进行演示。

在实际训练过程中，模型通常能在一次计算中处理序列的多个位置，并同时预测多个 "下一个 Token"，实现并行运算。工作原理就是通过因果 Mask，限制每个位置智能利用允许看到的上下文，而不会偷看后面的位置进行“作弊”。具体 Mask 矩阵将在后文细讲。

生成文字时，模型从已有上下文计算下一个 Token 的概率分布，选出一个 Token 并接到末尾，再用更新后的上下文预测下一步。重复这个过程，Token 序列逐渐变长完成整个序列的预测，之后 Tokenizer 再将 Token 序列还原成人能阅读的文本。

4.3 损失函数

在前面我们已经知道了误差是什么，它本质是一个数，表示预测值与真实值的差距。我们将这种差距通过人为定义的规则转化为可优化的数值，便得到了损失函数（Loss Function）。

损失函数是关于模型参数与真实答案的函数，提供了优化目标，通常是可导的、可最小化的。损失函数来源于不同的误差，也产生了不同的损失函数。损失函数的选取是决定模型能否高效地、正确地学习的关键。我们以常见的均方误差 MSE\text{MSE}MSE 结合线性回归进行讲解。

4.4.1 爬山算法

在正式介绍梯度下降之前，我们先介绍一个经典算法爬山算法（Hill Climbing）：是一种基于局部搜索的迭代优化算法。它从某个初始解出发，在每一步检查当前解的邻域，选择能使目标函数值更优的邻居作为下一步的解；若邻域中不存在更优解，则算法停止，并返回当前解作为结果。

用更容易懂得话来讲，就是从一个初始位置 x0x_0x0​ 开始，假设当前位于位置 xxx，每一步都查看邻域 f(x±Δx)f(x \pm \Delta x)f(x±Δx) 的函数大小，并沿着使得目标函数 f(x)f(x)f(x) 更优的方向移动，直到移动到某个点，在该邻域内不存在更优点为止，我们以某个二次函数为例，可见下图：

我们不难发现，因为我们的损失函数 L(θ)\mathcal{L}(\boldsymbol{\theta})L(θ) 本质上也是一个关于参数 θ\boldsymbol{\theta}θ 函数，也可以通过爬山算法来优化我们的参数使得损失达到最小。但实际过程中，我们却没有使用这种方法，原因是什么呢？

  • 高维下计算量巨大

假设模型有 10610^6106 个参数，那么爬山算法每个参数都需要尝试其正负邻域两个方向，那么每一步都需要尝试 2×1062 \times 10^62×106 个候选点，每个候选点都要做一次前向传播计算到底直到算出损失，计算量巨大。

（关于前向传播，会在4.4.2给出介绍）

  • 参数耦合导致局部最优

这里我们首先讲一下参数耦合，参数耦合是是数学建模、机器学习、控制理论以及物理学中常见的一个概念。简单来说，它指的是系统或模型中的多个参数之间存在相互依赖、相互影响的关系，而不是彼此完全独立的。如果一个参数发生变化，会导致另一个（或多个）参数也随之变化，或者一个参数的变化效果取决于另一个参数的值，我们就说这些参数是“耦合”的。

爬山算法通常只沿单个坐标轴或简单邻域试探。但深度学习参数高度耦合，真正下降的方向往往是多个参数联合变化的方向。所以爬山算法常常陷入局部最优解。

为了更好的讲解什么是参数耦合，我们举一个具体的例子：

f(x,y)=x2+y2+10xyΔx=Δy=ϵx0=y0=0f(x, y) = x^2 + y^2 + 10xy \\\\ \Delta x = \Delta y = \epsilon \\\\ x_0 = y_0 = 0 f(x,y)=x2+y2+10xyΔx=Δy=ϵx0​=y0​=0

如果沿着 xxx 轴走，那么 f(ϵ,0)=ϵ2f(\epsilon, 0) = \epsilon^2f(ϵ,0)=ϵ2；沿着 yyy 轴走，那么 f(0,ϵ)=ϵ2f(0, \epsilon) = \epsilon^2f(0,ϵ)=ϵ2。

会发现目标函数都上升，我们需要让函数值最小，所以算法认为这就是最优，停止并返回。

但实际上我们如果两个方向同时走，比如(ϵ,−ϵ)(\epsilon, -\epsilon)(ϵ,−ϵ)，那么 f(ϵ,−ϵ)=−8ϵ2<0f(\epsilon, -\epsilon) = -8\epsilon^2 < 0f(ϵ,−ϵ)=−8ϵ2<0，可以进一步降低。

造成这种问题的原因可以先简单这样理解，有的参数是相互之间耦合的，必须同时变化才会使得整体结果更优，但是只变化一个可能不会更优，甚至是更差。爬山算法只能离散的尝试每个参数的邻域，无法看到参数之间的联系。

  • 缺乏逃逸机制

爬山算法是贪心策略，只要邻域里没有更优点，它就停。它没有随机噪声、动量、重启等机制，很容易卡在局部最优或鞍点。

考虑一维函数 f(x)=x2+sin⁡(5x)f(x) = x^2 + \sin(5x)f(x)=x2+sin(5x)，它有很多局部极小值。爬山算法从某个点出发，会很快滑进最近的一个小坑，然后发现左右两边都比当前高，于是停住。但这个坑很可能不是全局最优。

总而言之，爬山算法因为其存在的问题，并没有成为主流的参数优化方式，但这种思想和机制是极为宝贵的，我们也在讲后面引出同一数学直觉的另一算法——梯度下降算法，这也是机器学习、人工智能领域的重要篇章。虽然爬山算法因为其弊端没有广泛应用到人工智能领域的参数更新中，但是其带来的数学直觉和机制提供了巨大的作用，在它的基础上也发展出来了一系列启发式算法，如模拟退火、随机重启、禁忌搜索、遗传算法、粒子群优化、蚁群算法和差分进化等等，感兴趣的可以自行研究。

4.4.2 梯度下降算法

经过了前面很多的铺垫，我们也是正式进入梯度下降算法了。前面的小节中我们已经知道，损失函数可以把模型预测结果“好不好”量化成一个具体的数作为评判指标，模型训练这一阶段的目的就是不断调整模型的参数，逐步降低这个损失。

假设目前模型的可学习参数记作 θ\boldsymbol{\theta}θ，记住一定是可学习的参数，而非固定参数。当参数改变时，模型预测就会跟着改变，损失也会随之改变，梯度下降就是根据损失对参数的变化趋势，反复更新参数的一种优化方式。

形象地，给定第 ttt 步参数为 θt\boldsymbol{\theta}_tθt​，则更新规则如下：

θt+1=θt−ηt∇θL(θt)\boldsymbol{\theta}_{t+1}=\boldsymbol{\theta}_t-\eta_t\nabla_{\boldsymbol{\theta}}\mathcal{L}(\boldsymbol{\theta}_t) θt+1​=θt​−ηt​∇θ​L(θt​)

不过这样理解可能不够明显，其实 ∇θL(θt)\nabla_{\boldsymbol{\theta}}\mathcal{L}(\boldsymbol{\theta}_t)∇θ​L(θt​) 就是损失函数关于所有可学习参数的偏导组成的。

如果只有一个参数，那么显然梯度就是该参数在 ttt 时的导数，当参数不只一个时，扩展为梯度，由所有参数的偏导数组成：

∇θL(θ)=(∂L∂θ1,∂L∂θ2,…,∂L∂θd)T\nabla_{\boldsymbol{\theta}}\mathcal{L}(\boldsymbol{\theta})= \left( \frac{\partial\mathcal{L}}{\partial\theta_1}, \frac{\partial\mathcal{L}}{\partial\theta_2}, \ldots, \frac{\partial\mathcal{L}}{\partial\theta_d} \right)^{\mathrm{T}} ∇θ​L(θ)=(∂θ1​∂L​,∂θ2​∂L​,…,∂θd​∂L​)T

梯度同时告诉我们每个参数对损失的影响方向和强弱，对于足够小的一步更新，沿着负梯度方向移动通常会使得损失下降。我们在微积分中学到过微分近似（线性近似）公式，其关于一阶导数的展开形式如下：

f(x+Δx)≈f(x)+f′(x)Δxf(x + \Delta x) \approx f(x) + f'(x)\Delta x f(x+Δx)≈f(x)+f′(x)Δx

扩展为用梯度表示，则可以得到下面式：

f(x+Δx)≈f(x)+∇f(x)TΔxf(\mathbf{x}+\Delta\mathbf{x})\approx f(\mathbf{x})+\nabla f(\mathbf{x})^{\mathrm{T}}\Delta\mathbf{x} f(x+Δx)≈f(x)+∇f(x)TΔx

我们将梯度下降里的参数和变量带入进去，便可以得到：

L(θ−η∇L(θ))≈L(θ)−η∥∇L(θ)∥22\mathcal{L}(\boldsymbol{\theta}-\eta\nabla\mathcal{L}(\boldsymbol{\theta})) \approx \mathcal{L}(\boldsymbol{\theta})-\eta\|\nabla\mathcal{L}(\boldsymbol{\theta})\|_2^2 L(θ−η∇L(θ))≈L(θ)−η∥∇L(θ)∥22​

所以当 η\etaη 足够小的时候，可以认为是线性近似，即损失降低。沿着负梯度方向移动，并且学习率 η\etaη 为大于零的正数，所以是减去梯度而非加上，这里要做好区分。不过只有理论还是太难懂了，我们结合具体的例子进行讲解。

因为训练集的样本可能有很多，每个样本都能产生对应的损失和梯度，所以计算梯度时我们也有以下不同的方式：

  • 全量梯度下降（Batch Gradient Descent，BGD）

    每次更新参数时，使用整个训练集计算梯度，求平均后更新一次参数。

    例如，训练集有五个样本，就在同一组当前参数下计算这五个样本的梯度，取平均后更新。我们前面使用五个点的例子就是这种方法。

    梯度能够准确反映整个训练集的当前损失变化方向，但当数据量很大时，每次更新的计算成本也比较高。

    我们前文展示的更新过程采用的就是这种方法。

  • 随机梯度下降（Stochastic Gradient Descent，SGD）

    每次更新参数时，只使用一个样本计算梯度，然后立即更新参数。

    例如，将五个样本随机打乱，使用第一个样本计算梯度并更新参数，再用更新后的参数处理第二个样本，依次进行。

    每次更新的计算成本较低，但单个样本的梯度可能与整个训练集的梯度差别较大，因此下降过程通常会有波动，损失也不一定每一步都下降。

    具体过程可见下图：

  • 小批量梯度下降（Mini-batch Gradient Descent，MBGD）

    每次更新参数时，使用一小批样本计算梯度，求平均后更新一次参数。

    例如，将五个样本随机打乱，分成大小为 2、2、1 的三个小批次，每处理完一个小批次就更新一次参数。

    它兼顾了计算效率和梯度的稳定性，也便于利用硬件进行并行计算，是深度学习训练中最常用的方式。实际讨论中，“SGD”有时也泛指采用小批量更新的方法，需要结合上下文区分。

我们在每次更新时，最基本的更新方式如下：

θt+1=θt−ηtgt\boldsymbol{\theta}_{t+1} = \boldsymbol{\theta}_t-\eta_t\mathbf{g}_t θt+1​=θt​−ηt​gt​

其中，gt\mathbf{g}_tgt​ 表示这一步使用的梯度。

这个方法是最基本的方法，仅需要当前参数、梯度以及学习率即可完成更新，但缺点也显而易见，它无法参考训练过程中的其他信息，只是极限的按照一个参数进行固定的更新方式。为了优化这种更新方式，我们可以增加一些信息进行参考，例如前几步的梯度、不同参数的梯度大小等，便由此得到了其他更新方式。考虑篇幅，我们仅介绍最重要的几个方法：Momentum、RMSProp、Adam等。

这里需要区分一下前面介绍的三种梯度下降（全量、随机和小批量梯度下降）与这里方式的区别。前者决定每次使用哪些样本计算梯度，后者决定得到梯度以后怎样去更新参数，这里读者要自行做好区分。

  • Momentum

Momentum的思路是记录之前的方向。假设我们连续多步得到的梯度都指向一个相近的方向，这样持续出现的信息，可以帮助我们判断参数的变化趋势。

这里的方向不要理解为正负，而是参数向量所指向的方向。假设目前向量维度为2，连续几步梯度都是 (+2,−1)(+2, -1)(+2,−1) 附近，说明该阶段变化朝向 (+2,−1)(+2, -1)(+2,−1) 这个方向，而且第一个参数走的比第二个参数要快，因为数值更大。如果下一步变成 (+1.9,−0.9)(+1.9, -0.9)(+1.9,−0.9)，那么也算方向接近。

这里正式介绍一下，Momentum 通常翻译为动量，它的基本思路就是：保留一部分之前的方向信息，再加入当前梯度，得到这一步使用的更新方向。结合动量这个名字，也可以知道它实际上可以理解为让惯性来参与更新。

  • RMSProp

前面介绍的 Momentum，会把之前的梯度记录下来，帮助我们决定这一步使用的更新方向。不顾哦我们还可以考虑另一个问题，即不同参数对应的梯度，数值大小可能相差很多。

比如假设我们当前又两个参数，其对应的梯度为 (20,1)(20, 1)(20,1)，学习率为 0.10.10.1。如果我们直接使用普通梯度下降，那么这一步参数变化量就是 (−2,−0.1)(-2, -0.1)(−2,−0.1)。可以看出第一个参数的变化幅度是第二个参数变化幅度的 202020 倍。

如果这种差异连续出现，那么使用同一个学习率，就可能让一部分参数变得异常剧烈，亦或者是一部分参数变得极为缓慢。我们希望的是根据每个参数最近的梯度情况，分别调整它们的更新幅度。

RMSProp 的基本思路就是：记录每个参数近期梯度的大小，再用这个记录对当前梯度进行缩放。

这里的“大小”，一般用梯度的平方来记录，这样出现 333 与 −3-3−3 时，平方都是 999，即保留了大小，也取消了方向上带来的抵消，同时使得较大的数值表现更为敏感。

vt+1=ρvt+(1−ρ)gt2v_{t+1}=\rho v_t+(1-\rho)g_t^2 vt+1​=ρvt​+(1−ρ)gt2​

其中，gtg_tgt​ 是当前梯度，ρ\rhoρ 是我们设置的系数，范围为 0≤ρ<10\leq\rho<10≤ρ<1，用来控制历史信息保留多少、当前信息加入多少。它与前文中的 β\betaβ 起到类似的作用，这里使用不同字母，是为了方便区分。

这里我们可以发现，此处仍然使用了指数移动平均，只是记录的信息变为了梯度的平方以保留梯度的大小这一信息。

接下来我们讲一下学习率调度（Learning Rate Scheduling），说白了就是动态的学习率。

前面的例子我们都使用的是固定的学习率，但实际上训练的前期和后期对更新幅度的需求是大概率不同的，比如前期举例较好的参数位置较远，则需要用较大的学习率推进，而后期可能已经逼近损失较低的区域，较大的学习率会使得参数反复越过合适的位置，因此可以尽量缩小学习率，让调整更细致。

这里需要注意，学习率控制更新的缩放比例，实际移动距离还取决于梯度以及优化器的历史信息。

这里我们介绍几种调整学习率的方法。

  • 分段衰减

先介绍一种简单的，分段衰减。其实就是写一个关于 ttt 的分段函数，到达某个轮次之后改用不同的学习率，比如我们可以做出下面这种安排：

在这种例子中，每次学习率的改变比例可以记作 γ\gammaγ，表示到达指定阶段时，将学习率乘以该比例，可以理解为这个比例为衰减系数，然后得到新的学习率。这是分段衰减的一种典型形式。

  • 余弦衰减

分段衰减是在指定的位置进行改变，某种意义上整个变化不平滑、不连续，为此我们也可以用一种方法让学习率的变化相对平滑，从较大的数值主键过渡到较小的数值。余弦衰减就是这样的一种安排，利用一段余弦曲线计算训练进度所对应的学习率。

先只考虑一个衰减阶段。用 t=0t=0t=0 表示阶段开始，用 t=Tt=Tt=T 表示阶段结束，一种常见写法为：

  • Warmup

前文说到，训练前期用较大的学习率推进，但有些训练却从较小的学习率开始？思考下原因。

因为，训练刚开始的时候，模型参数刚初始化，梯度和中间表示可能还会出现明显的变化，对于优化器，也刚开始累积历史记录，直接采用较大的学习率则可能会导致初始几次参数更新过于剧烈。

因此，我们可以先使用较小的学习率，在逐渐提高到目标值，这种安排称之为学习率预热（Warmup）。

在预测阶段，模型仍然正常计算梯度、更新参数，仅仅只是学习率从小到大变化，也不是先等待一段时间再开始训练。

最容易理解的预热方法是线性预热，也就是每一步都提高相同的数值，直到达到目标值，写法如下：

ηt=ηstart+(ηpeak−ηstart)tTwarmup,0≤t≤Twarmup\eta_t =\eta_{\mathrm{start}} +\left(\eta_{\mathrm{peak}}-\eta_{\mathrm{start}}\right) \frac{t}{T_{\mathrm{warmup}}}, \qquad 0\leq t\leq T_{\mathrm{warmup}} ηt​=ηstart​+(ηpeak​−ηstart​)Twarmup​t​,0≤t≤Twarmup​

最后，我们来讲一下优化器和学习率的关系。很多人有这样的误解，为什么前面的优化器已经有的有部分自适应了，还需要进行学习率的动态调度呢？

我们以 Adam 为例，先把其参数更新公示写出来：

θt+1=θt−ηtm^t+1v^t+1+ϵ\boldsymbol{\theta}_{t+1} =\boldsymbol{\theta}_t -\eta_t \frac{\hat{\mathbf{m}}_{t+1}} {\sqrt{\hat{\mathbf{v}}_{t+1}}+\epsilon} θt+1​=θt​−ηt​v^t+1​​+ϵm^t+1​​

可以看到， Adam 前面仍然乘以一个基础学习率，得到实际更新的变量，因此学习率这一部分可以同时变化，对于第 jjj 个参数，可以进一步写成：

这里也区分一下前面的偏差修正，Adam 的偏差修正用于记录从 000 开始训练带来的统计偏差；Warmup 则直接控制基础学习率的变化，让训练初期的更新更温和，它们做的事情不同。

到这里，一次梯度下降产生的更新过程就可以串起来了：首先根据进度，确定学习率，然后取出全部样本或者一部分样本，计算模型输出、损失和梯度。优化器根据梯度以及已有的记录计算更新量，并使用这一步的学习率进行参数的更新。完成后进入下一个循环。

我们要区分下面三个问题：

问题 对应的安排 例子

如何更新参数 优化器 普通梯度下降、Momentum、RMSProp、Adam
学习率如何变化 学习率调度 分段衰减、余弦衰减、Warmup

例如，“小批量训练，使用 Adam，前 100010001000 步预热，之后使用余弦衰减”，这几种安排可以共同出现在同一次训练中，你可以将不同问题的答案进行排列组合。要记住学习率可以根据训练进度进行动态调整，这种调整时可以和优化器同时使用而不冲突的。

我们也要区分学习率曲线和损失曲线并非一样，前者展示学习率的变化，后者表示模型的损失如何变化。实际上，模型的损失一般会收敛到某个值，不一定是一直变小的，也不代表每一步都一定降低。

如果模型效果不好，只是简单地减小学习率也不一定能解决问题，具体情况需视情况而定。

4.4.4 算法的优势与局限

梯度下降通过借助梯度信息，使得它相比起爬山算法效率更高。因为梯度下降只需算到底一次便可以得到所有的梯度，进而求出变量；爬山算法则是每个参数的改变都需要算到底一次才能得到变化，计算量极大。而且梯度下降可以实现多个参数的同时变化，不过参数之间的耦合仍会一定程度下影响路径更新，比如狭长谷地中的来回摆动就是一个例子，不过梯度下降可以使用优化器缓解这种负面影响。

同时梯度下降可以借助梯度来实现对历史信息的保存，这是一个优点，各类优化器以及学习率的动态调整为梯度下降提供了更多的更新手段。

爬山算法中的一个大问题就是局部最优和鞍点问题，这些问题在梯度下降中仍然存在，比如面对函数：

f(x,y)=x2+y2+10xyf(x,y)=x^2+y^2+10xy f(x,y)=x2+y2+10xy

在原点处，它的梯度为：

∇f(0,0)=[2x+10y2y+10x]∣(0,0)=[00]\nabla f(0, 0) = \left. \begin{bmatrix} 2x + 10y \\ 2y + 10x \end{bmatrix} \right|_{(0,0)} = \begin{bmatrix} 0 \\ 0 \end{bmatrix} ∇f(0,0)=[2x+10y2y+10x​]​(0,0)​=[00​]

但梯度下降通过优化器维持历史信息，可以一定程度上解决这部分问题。例如面对上面这个例子时，优化器可以借助历史信息调整梯度的变量，使之不再是 (0,0)(0, 0)(0,0)，进而逃逸出鞍点或局部最优点，移向其他位置。

总的来说，梯度下降及其相关方法的主要优势时可以借助损失函数的可微结构，高效的获取参数的变化信息，并以此为据进行更新，改善了爬山算法中逐个邻域试探的效率和更新方式，但当面对复杂损失曲面的时候，其带来的困难仍需面对。

关于梯度下降的“算到底”，实际上指的是前向传播，而信息的返回则是反向传播，这部分将在下一章节中详细讲解。
